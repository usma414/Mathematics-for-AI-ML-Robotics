## Key Formula

For an `m × n` matrix:

``` text
rank(A) + nullity(A) = n
```

where `n` is the number of columns.

## Why this matters for AI and Robotics

Linear algebra provides the language for vectors, matrices,
transformations, systems of equations, dimensionality, information loss
and many machine-learning computations. Later topics such as
eigenvalues/eigenvectors, least squares, projections and singular value
decomposition build directly on this foundation.
